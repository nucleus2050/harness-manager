# 设置与全量配置备份设计

## 目标

补齐侧栏统计信息，并新增设置页面。设置页面支持界面语言偏好保存，以及将当前应用配置全量导出、导入。

## 范围

包含：

- 侧栏统计显示任务套件、技能、MCP、AGENTS.md 数量。
- 侧栏新增 `设置` 入口。
- 设置页面支持语言切换：中文、English。
- 语言选择保存到 `config/settings.json`。
- 全量导出为 zip。
- 全量导入 zip，导入前自动备份当前配置。

不包含：

- 深度重构所有历史文案为完整 i18n 资源。
- 自动合并导入配置。
- 写入外部工具的真实配置文件。

## 全量导出范围

导出 zip 包含：

- `data/`
- `assets/`
- `skills/`
- `config/`

## 全量导入策略

第一版采用全量替换：

1. 校验 zip 中路径不越界。
2. 导入前生成当前配置备份。
3. 删除当前 `data/`、`assets/`、`skills/`、`config/`。
4. 将 zip 内容复制到应用根目录。
5. 刷新界面。

## UI

侧栏统计卡改为 2x2：

- 任务套件
- 技能
- MCP
- AGENTS.md

设置页包含：

- `设置`
- `界面语言`
- `中文`
- `English`
- `配置备份`
- `导出全部配置`
- `导入全部配置`
