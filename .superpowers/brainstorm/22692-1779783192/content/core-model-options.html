Skill 管理工具：核心模型对比

基于你确认的方向，pkg 是数据库里的集合；skills 是工具目录中的真实文件；导出时才生成离线包。

推荐：统一库 + DB pkg + 离线导出

skills/

pkg -> skills

目标客户端
导出离线包：pkg.json + skills 内容

统一管理模型

工具目录保存所有 skill 内容，数据库保存 pkg 关系和安装记录；导出时生成可分享包。

备选：pkg 目录即真实包
packages/work-a/
packages/work-b/
每个包复制一份 skills

实体包模型

分享直观，但容易重复存储，同一 skill 在多个 pkg 中版本漂移。

备选：客户端目录优先
直接管理 Codex skills
直接管理 Claude skills
直接管理 OpenCode skills

客户端优先模型

实现简单，但 pkg 抽象弱，迁移和回滚能力差。
