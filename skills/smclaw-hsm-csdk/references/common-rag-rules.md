# HSM C SDK 公共 RAG 规则

本文件供 `smclaw-hsm-csdk` 下所有子任务引用。产品固定为 HSM，但文档版本必须由用户确认。SDK 函数签名、参数 IN/OUT、结构体、宏、返回值必须来自 `smclaw-rag` MCP、用户提供的官方 HSM C SDK 文档，或 `/csdk_init` 工程生成的 `sdk-api-docs/api.md`；不得编造。

## 产品和版本

- 产品固定使用 `product=HSM`。
- 版本必须明确，例如 `v3.0.1.0`。
- 用户未给版本时，先列可用 HSM 版本或询问用户。
- 调用 `smclaw_rag_search` 时，`product=HSM`、`version=<用户确认版本>`，`query` 不重复写 HSM 和版本号。

## 检索策略

- 查询应聚焦 C 语言接口手册、SDF、SDIF、目标函数名、参数名、结构体名、宏名。
- 单接口示例至少查询目标函数名和结构化字段，例如 `SDF_GenerateRandom 函数签名 参数 返回值 C语言接口手册`。
- 场景示例必须查询场景中每个 SDK 调用。
- 配置和安装问题优先查询 C SDK 配置、`hsmConfig.ini`、头文件、库文件、运行环境。

## 必须确认的 SDK 事实

生成 C 代码前必须确认：

- 函数名称和完整签名。
- 每个参数的方向、类型和含义。
- 返回值含义。
- 相关结构体和宏。
- 是否需要先打开设备和会话。
- 是否需要清理密钥句柄或关闭资源。

如果 RAG 未检索到目标接口，停止生成代码，要求用户补充接口文档、函数签名、参数说明和结构体定义。

## 来源引用

输出必须包含来源，至少包含：

- `source_name`
- `source_path`
- `chunk_index`

如果结果包含 `heading`、`page_number`、`sheet_name` 或 `slide_number`，一并引用。

## 安全边界

- 不伪造真实设备地址、生产密钥索引、证书、权限码或口令。
- 设备内部密钥索引、权限码、用户 ID 等真实资源参数必须询问用户，或标注为测试默认值。
- 不自动修改用户工程文件。
- 不自动运行真实设备测试。
