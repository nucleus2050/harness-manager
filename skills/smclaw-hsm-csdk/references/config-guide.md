# HSM C SDK 配置向导

用于用户要求生成 HSM C SDK 配置样例、`hsmConfig.ini` 说明、设备连接配置或运行时配置说明的场景。

进入本子任务后，先遵守 `references/common-rag-rules.md`。

## 子任务引导

如果用户没有明确配置目标，先给出：

```text
请选择要生成的 HSM C SDK 配置内容：

1. hsmConfig.ini 配置样例
2. 配置字段说明
3. 连接配置检查清单
4. 测试工程 /csdk_init 的配置说明
5. 其他，请说明
```

## 输出内容

- 配置文件用途。
- `hsmConfig.ini` 样例。
- 设备 IP、端口、passwd、日志路径等字段说明。
- 敏感字段处理原则。
- 如何按用户实际环境替换配置值。
- RAG 来源引用。

## 规则

- 不直接修改用户配置文件。
- 不伪造真实设备地址、真实口令或生产密钥信息。
- 如果文档或测试框架明确默认行为，例如 `passwd` 为空时补 `88888888`，可以说明该行为并引用来源。
- 如果字段含义无法从 RAG 确认，标记证据不足。

## 输出模板

```text
当前可以生成 HSM C SDK 配置样例，但以下值需要按你的环境替换：

- 设备 IP
- 设备端口
- 连接口令或访问控制码

配置样例：

[Host 1]
ip=192.168.1.10
port=9000
passwd=88888888

字段说明：
- ip：HSM 设备地址。
- port：HSM 服务端口。
- passwd：连接口令；请按实际设备配置替换。

来源：
- source_name, source_path, chunk_index
```
