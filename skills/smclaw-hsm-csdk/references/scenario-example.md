# HSM C SDK 场景化示例规则

用于生成 HSM C SDK 业务场景示例。一个场景只覆盖一个业务流程，不跨多个无关流程。

进入本子任务后，先遵守 `references/common-rag-rules.md`。

## 支持的首批场景

- 随机数生成。
- SM3 摘要。
- SM2 签名验签。
- SM4 加解密。

## 子任务引导

```text
请选择场景示例：

1. 随机数生成
2. SM3 摘要
3. SM2 签名验签
4. SM4 加解密
5. 其他，请说明
```

## 规则

- 场景中每个 SDK 调用都要有 RAG 来源支撑。
- 需要真实设备预置资源时，先确认密钥索引、权限码等参数。
- 输出包含流程说明、C 代码、编译提示、运行提示和来源引用。
- 不写 Unity 测试框架代码。
- 不生成复杂业务系统。

## 场景流程要求

- SM3 摘要：通常使用 `SDF_HashInit`、`SDF_HashUpdate`、`SDF_HashFinal`。
- SM2 签名验签：先确认使用外部密钥还是内部密钥索引。
- SM4 加解密：先确认使用临时会话密钥、外部密钥还是内部密钥索引。
- 随机数生成：确认输出长度和缓冲区大小。
