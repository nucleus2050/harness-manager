# HSM Java SDK 场景化示例规则

用于生成 HSM Java SDK 业务场景示例。一个场景只覆盖一个业务流程，不跨多个无关流程。

进入本子任务后，先遵守 `references/common-rag-rules.md`。

## 支持的首批场景

- 随机数生成。
- SM3 摘要。
- SM2 签名验签。
- SM4 加解密。

## 子任务引导

```text
请选择 Java SDK 场景示例：

1. 随机数生成
2. SM3 摘要
3. SM2 签名验签
4. SM4 加解密
5. 其他，请说明
```

## 规则

- 场景中每个 Java SDK 调用都要有 RAG 或本地文档来源支撑。
- 需要真实设备预置资源时，先确认 key index、证书 index、权限码、userId 等参数。
- 输出包含流程说明、Java 代码、编译提示、运行提示和来源引用。
- 不写 HsmSessionTestCase。
- 不写测试框架代码。
- 不生成复杂业务系统。

## 场景流程要求

- SM3 摘要：确认 Java SDK 对应摘要方法和返回类型。
- SM2 签名验签：先确认使用外部密钥、内部密钥索引还是证书。
- SM4 加解密：先确认使用临时会话密钥、外部密钥还是内部密钥索引。
- 随机数生成：确认输出长度和返回类型。
